# T035 第二阶段 v4：提问侧在结尾学老师，补普通对话数据

- 版本：v1（2026-09-26）
- 设计和执行：执行方（兼设计）。用户 2026-09-26 选“训 v4”。
- 代码：`round6/stage2/build_targets.py --teacher-end`、`teacher_label_l20.py --end-user`；数据 `round6/leader_v1`（流程 v1.4、`make_batch.py --normal3`）；
  作业 `worker_stage2_v4.yaml`、`worker_stage2_v4_eval.yaml`。

## 起因

v3 + v3.1 还有三处没达标：普通对话误报 1.36%（v1 0.68%）、思考侧正常问题扫描 6/194（标准 ≤ 3）、提问侧通用头 F1 77.2（论文 84.7）。

## 做法

- **提问侧读点**：Qwen3Guard-Stream 的 query 头只在 user 轮结尾的 `<|im_end|>` 处训练和读取。v4 整模型训练时，提问文本只在最后一个内容位置学老师在结尾的输出（v3.1 只重训了这个头，主干没有跟着学）。
- **normal3 数据**（3,154 条，裁判后全部可用）：40% 英文日常请求（20 个领域）、35% 日常同形词、25% v1.3 的政治同形词（新编号，新文本）。
- 其余（起点、红线头目标、警觉档 0.4、选轮次）同 v3。

## 验收

1. 普通对话误报接近 0.68%。
2. 正常问题扫描思考侧 ≤ 3。
3. 提问侧通用头 F1 向 84.7 靠近。
