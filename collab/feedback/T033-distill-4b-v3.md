## 通用头

- 回答侧：Qwen3Guard 基准平均 F1 **75.1**（Qwen3Guard-Stream-0.6B 论文 78.3；v1 31.4）。
- 提问侧 v3 有缺陷：老师的 query 头只在 user 轮结尾的 `<|im_end|>` 处训练和读取，v3 却蒸馏了提问内部每个 token 的输出
  （这些位置没训练过）。结果 194 条正常提问里 189 条被判有害，基准里 74% 的安全提问被判有害。
- **v3.1 修正**：老师只在 `<|im_end|>` 处重跑（47,897 条提问，4 分钟，`teacher_label_l20.py --end-user`）；冻结 v3，
  只在学生的最后一个提问 token 上重训提问侧通用头（`train_general_user.py`，42,523 条，16 轮，选第 12 轮，
  calibration KL 0.17，对老师判定的 AUC 0.95–0.97）。其余 344 个张量与 v3 逐位相同，红线结果全部沿用。
  提问平均 F1 72.3 → **77.2**（论文 84.7），基准安全提问误报 73.8% → 33.4%（Qwen3Guard 自身 30.6%）。
