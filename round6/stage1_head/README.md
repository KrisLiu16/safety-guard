# 第六轮第一阶段：只重训读出头（设计）

## 依据

| 证据 | 结论 |
|---|---|
| T004：冻结特征上的线性探针，在 Run A dev 上区分“复述有害请求”和“真有害”，AUC 0.995；现在的头只有 0.791 | 区分信息在主干里，现在的头没读出来 |
| T005：只换决策规则，复述类误报仍有 11–31% | 光调阈值不够，要改读出 |
| T014：同一探针在官方 thinking 集上流式 AUC 0.889，头 0.784；但在 prefix_v2 上 0.839，头 0.903；Run A 上定的阈值换到别处，误报升到 29–46% | 只用 Run A 训练，会用公开数据上的能力换 luna 风格上的能力；必须混合数据训练，阈值在混合校准集上拟合 |

所以第一阶段：**冻结主干，只重训助手侧的读出头**（512 维投影层 + 三类风险头，结构不变），用混合数据，从现有头的权重热启动。代价小，几分钟就能训一版，适合多试几种配比。主干全参训练留到第二阶段，看第一阶段的结果再定。

## 数据（全部按位置标注，与 T004 的位置标签一致）

| 来源 | 内容 | 位置标签 |
|---|---|---|
| prefix_v2 train（第五轮原训练集，33,311 条） | 公开数据、v12、rubric、长背景 | 沿用第五轮的 anchors：安全记录的内部位置是弱标签（权重 0.1）；完整目标加中性后缀之后的位置是硬标签 |
| Run A train（v14 2×2，39,700 个词） | 复述拒答、顺从、跑偏、正常回答 | 安全回答所有位置 safe；不安全回答起点前 safe、起点后 unsafe；起点引用内部不训练。T010 重定起点后替换 |
| S2 / S5 安全一半（放量后） | 难负例、长篇安全思考 | 所有位置 safe |
| R 切片（先 dev 和 calibration，train 待定） | 国内口径重判的整段标签 | 整段和末尾位置按新标签 |

## 流程

1. **特征缓存**（L20，推理，不训练）：对上面各来源的训练记录走冻结主干，用 T004 的钩子方式缓存头的输入特征（1024 维），每条记录最多取 24 个位置；同时记录每个位置的标签和权重。评测集不缓存，评测时整段前向。
2. **训练读出头**（在缓存上训练，分钟级）：几种数据配比和类别权重各训一版，只用训练集拟合；用 Run A calibration + prefix_v2 calibration 的混合校准集选温度和阈值。**这一步是训练，开跑前请用户确认。**
3. **评测**（L20，推理）：把新头装回运行时，走与 T014 相同的逐位置前向，在 Run A dev、prefix_v2 dev、官方 thinking 集（只观察）上，与现在的头按同一套规则比较。

## 通过标准（第一阶段）

- prefix_v2 dev 的流式 AUC 不低于现在的头（0.903），误报在混合阈值下不高于现在的头；
- Run A dev 上复述类误报明显低于现在的头（14.9%–29.9%）；
- 官方 thinking 集只观察：希望流式 AUC 接近 T014 探针的 0.889，误报低于第五轮决策规则的 23.9%。

## 变体与文件

先不动类别头的输入：类别头和风险头读的是同一个 512 维投影。T004 里在投影上训练的探针已接近在 1024 维输入上训练的（AUC 0.987 对 0.995），所以同一份缓存训练两个变体：

- `risk`：只重训 512→3 的风险层，投影和类别头不动。权重可以直接替换，运行时和模型包都不用改。
- `full`：重训投影和风险层。类别头的旧权重保留，但它读到的投影已经变了；报告里单独标出，这一轮不处理。

第一版缓存只放 prefix_v2 和 Run A。S2、S5 安全一半的 pilot 只有约 200 行，按默认配比会被严重高估，等放量后再加入。

| 文件 | 在哪跑 | 作用 |
|---|---|---|
| `make_stage1_input.py` | Mac | 从 Run A 的 train 里抽 8,000 个词，加上全部 calibration 词；不含 dev |
| `cache_features_l20.py` | L20 | 缓存头的输入（1024 维）和投影（512 维），同时写出位置标签和权重，并保存现有头的权重；自检方式同 T004/T014 |
| `train_head.py` | L20（CPU 也能跑） | 在缓存上训练 `risk` 和 `full` 两个变体：从现有权重热启动，按来源内类别平衡加权交叉熵，加上向初始权重的 L2 约束；按 calibration 选 epoch，不读 dev |
| `eval_head_l20.py` | L20 | 把新头装进模型，在 Run A、prefix_v2 和官方集上逐位置打分；自检同时确认运行时用的是新权重。现有头直接用 T014 的结果 |
| `analyze_stage1.py` | Mac | 现有头和各变体使用同一套规则：温度和阈值在 Run A 与 prefix_v2 的混合校准集上拟合，每个“来源/语言”分层误报都不超过 5%；报告三组数据的误报、召回和流式 AUC |
| `worker_cache_v1.yaml`、`worker_train_eval_v1.yaml` | 集群 | 两个 L20 作业 |
| `test_stage1_cpu.py` | Mac | 5 项单测（需要 torch 和 numpy）：输入、缓存（假引擎）、训练、评测循环、对比分析 |

## v2：按“只审红线”口径改标签（2026-09-24）

口径见 [POLICY-redline-scope.md](../../collab/feedback/POLICY-redline-scope.md)。v1 的目标在三处不再成立：Run A 的复述拒答在红线内要标“有争议”；红线以外的有害内容（Run A 不安全样本的大部分、prefix_v2 公开数据的大部分）要标 safe；决策规则要把“有争议”计入截断。T017 的特征不依赖标签，直接复用，只换目标：

| 步骤 | 在哪跑 | 做什么 |
|---|---|---|
| 红线标注 | Aster | [round6/redline_v1](../redline_v1/README.md)：裁判 v4 只记事实，规则表定等级，两级二分找“有争议”和“风险”的起点。覆盖 Run A 第一阶段输入（train 8,000 词 + calibration）、Run A dev、prefix_v2 助手侧（train / calibration / dev） |
| `relabel_cache.py` | L20 作业第一步（CPU） | 按标注结果给 T017 缓存的每个位置写三类目标（0 safe / 1 unsafe / 2 controversial，与头的类别顺序一致）。位置的字符偏移按缓存时的方式重新分词得到；起点分句内部、不可用、被剔除的位置不训练 |
| `train_head.py --labels3` | L20 | 三类交叉熵，来源内三类平衡；calibration 用截断分数 1 − p(safe) 选 epoch。没有三类标签的来源不参与，并在报告里列出 |
| `eval_head_l20.py` | L20 | 新增变体 `init`（现在的头），三个头在同一次运行里评测；Run A 行新增 `char_ends` |
| `analyze_redline.py` | Mac | 截断分数 1 − p(safe)；温度和阈值只在混合校准集上拟合；报告误报（按正常内容 / 红线外有害 / 红线话题 / 其他敏感分层）、按等级分开的召回、Run A 上“红线内容出现前就截断”的比例 |
| `worker_redline_v2.yaml` | 集群 | 一个 L20 作业：改标签 → 训练 → 评测 |
| `test_redline_stage1_cpu.py` | Mac | 4 项单测（只需 numpy）；`test_stage1_cpu.py` 新增三类训练和 `char_ends` 两项（需要 torch） |

### 通过标准（v2）

- **正常内容**：Run A dev 和 prefix_v2 dev 里 `normal` 层的误报不高于现在的头，目标接近 0；
- **红线外有害**：`non_redline_harm` 层的误报明显低于现在的头（现在的头按第五轮口径会截它们）；
- **红线**：“有争议”和“风险”两档的召回都不低于现在的头；Run A 上“红线内容出现前就截断”的比例不高于现在的头；
- 官方 Qwen3GuardTest 的标签口径不同，只观察。

## v3 诊断：读出上限（T028）

T018 v3.1 的结论：
- full 头最好：normal 零误报，Run A 有争议的召回 29–39%，风险的召回 15–22%，流式 AUC 0.83–0.86；
- 位置级 calibration AUC 到第 4 轮还在涨（0.865）。

T028 用同一份缓存和三类目标做三组训练，看冻结主干时读出能到多高：
- full 训练 16 轮；
- full 训练 16 轮，学习率 3e-3，不加 L2 约束；
- `wide`：全新初始化的 1024→2048→512→3 读出。只作诊断，形状和运行时的头不同，不部署。

如果三组都停在同一水平，瓶颈就在主干最后一层的特征上，下一步训练主干（第二阶段）。

官方 thinking 集的标签口径不同。T027 用 redline_v1 的裁判给它标上我们的标签，`analyze_redline.py --official-labels` 按我们的标签重算官方集一列，并给出（官方标签, 我们的等级）每一格的截断比例。
