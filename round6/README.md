# 第六轮：计划、决定与进度

2026-09-24。**交接说明见 [HANDOFF.md](HANDOFF.md)。** 依据：[第五轮复盘](../round5/DIAGNOSIS.md)、外部评估（数据、训练设计、提质、速度四部分）、[第 1 步决策规则实验](decision_rule/RESULTS.md)。

## 用户已定的决定

| 项 | 决定 |
|---|---|
| 逐位一致 | 放弃 canonical32 的“整段与流式逐位一致”。只保留流式一条路径，整段请求当作一次大追加；BPE 回滚只提交倒数 2–4 个 token 之前的状态；数值抖动靠校准阈值、温度和防抖吸收。上线前实测漂移分布 |
| 速度目标 | 单次分类 P95 ≤ 20 ms 的前提下，单张 L20 的 ITPS 最大化 |
| 裁判模型 | dsv41flash（Aster 模型配置由用户添加）。不用 luna 自己当裁判 |
| RL | 停止分类 RL。改用代价敏感 CE、稠密前缀监督、安全流最大风险分损失、流式/端点双头 |
| 造数 | v14 2×2 格式；Run A 5 万词（并发 285），Run B 其余约 29 万词（并发 150）。见 [response_v14/BATCH_PLAN.md](response_v14/BATCH_PLAN.md) |

## 评测约定

- 官方 Qwen3GuardTest 只做观察，不拟合、不选模。
- 选模看开发集的阈值无关指标（AUC、同误报率下的召回）并报置信区间。阈值只在校准集上拟合。
- 新增 thinking 风格分层，每层至少 1,000 个负例：Run A 的 dev/calibration 词族先顶上，v15 长流随后补充。
