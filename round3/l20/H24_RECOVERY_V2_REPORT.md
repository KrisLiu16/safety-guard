# 窗口结构恢复 v2：局部改善，未完成质量恢复

日期：2026-09-23。此轮从同一 H24 分类器出发，固定分类头，更新完整语义主干；没有 LoRA、删层或生成式文本输出。训练输入仍为 128 篇中英长文档（291,727 token）和 512 个短输入，短输入只用于同教师保持损失，不使用来源硬标签。32 篇不同域名的长文档只用于开发选择。

**结论：不晋升 W512 为默认模型。** 表示距离小幅下降，但分类分布 KL 与部分风险召回未恢复；不同代理指标不能互相替代。

| W512 验证项 | 恢复前 | 选定检查点后 |
|---|---:|---:|
| 长文本平均余弦距离（越小越接近教师） | 0.01861 | 0.01793 |
| 长文本风险分布 KL（越小越接近教师） | 0.01000 | 0.01339 |
| 官方 thinking 最终读出召回 | 71.7% | 73.6% |
| 官方 thinking 安全误报 | 10.6% | 10.6% |
| 官方 response_loc 最终读出召回 | 89% | 89% |
| 官方 thinking_loc 最终读出召回 | 76% | 76% |

未改窗口的同源 H24 thinking 召回为 77.4%、thinking_loc 为 78%。上述官方子集仅 250 条且已经用于多次回归观察，不是新鲜盲测，不能声称统计显著或官方流式定位得分提升。

检查点选择只用长文本 dev 余弦距离，候选步数 0/32/64/96/128。W512 选中第 128 步；全历史对照选中第 0 步，其导出权重 SHA-256 与原 H24 完全相同。该门槛确实阻止了把训练后更差的全历史检查点替换进去，但余弦距离本身不足以充当安全验收指标。

本轮同时调整了训练目标和学生残差流精度，不能将变化完全归因于其中一项。FP32 主参数/优化器用于训练、BF16 残差计算与冻结教师对齐；分类头冻结。完整/分块读出的最大风险概率差为 0.000622，检查通过。

全部检查点保存在 PVC `safety-guard-base-compare-data` 的 `/work/output/window_recovery_v2/{full,w512}/classifier.safetensors`；本地有[原始报告、预测与选择记录](window_probe/recovery_v2_results/output/window_recovery_v2)。Job 已完成并释放 GPU。

后续优先事项：扩充自然对话与长程风险/引用/否定的恢复数据；继续使用足量的用户侧和助手侧数据降低误报；扩大独立校准及最终保留测试集。W1024 作为状态更省且本次小样本硬分类未退的备选保留，仍未通过项目政策/生产服务验收。暂不把 MoE 或 RL 加上去掩盖当前问题。
