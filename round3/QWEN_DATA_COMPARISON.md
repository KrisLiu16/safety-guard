# 当前语料是否足够，以及 Qwen 的数据分层

2026-09-23 核查。当前下载的 20,000 篇自然文本按 Qwen3Guard tokenizer 为 19,377,416 token；够做接入/管线试验，不足以据此宣称从零训练出成熟 0.619B 分类主干。完整 FineWeb2 中文和 FineWeb-Edu 公开源的规模足以支持下一轮扩量，但质量、任务覆盖和预处理不能用下载规模代替。

## Qwen3 基座

[Qwen3 报告 §3](https://arxiv.org/html/2505.09388v1)披露约 36T 预训练 token、119 种语言/方言，内容含书籍、多语言文本、代码、STEM、推理及合成数据。还使用 Qwen2.5-VL 提取 PDF 文本，经 Qwen2.5 清理，并用 Qwen2.5/Math/Coder 合成教材、问答、指令和代码。报告没有提供完整可下载语料及逐源配比。

这是 Qwen3Guard 所继承的语义基础。不能拿 Guard 的百万级安全样本与从零语言预训练等同，也不能要求一个中英专用分类器机械复制 Qwen 的全部训练规模。

## Qwen3Guard

[Guard 报告 §3.2、§4](https://arxiv.org/html/2510.14276v1)披露 Gen 安审集超过 1.19M 样本，混合人工与合成记录，覆盖用户提问和助手回答。其配方包含关键词引导的提问、表面形式相近的正负对照、多来源回复、模型裁判和翻译扩充。Stream 继承预训练 Qwen3 主干，并将样本标签转为逐 token 风险边界：前缀续写结果提供候选信号，再让裁判仅根据已见前缀复核，最后训练分类损失。

截至本次核查，[官方仓库](https://github.com/QwenLM/Qwen3Guard)列出了模型和 Qwen3GuardTest，没有找到完整 1.19M 训练集或逐 token 训练标签下载。论文评测表中的 ToxicChat、WildGuardTest 等不能据此当作其训练来源；Qwen3GuardTest 保持测试用途。PolST 在论文中是内部中文评测数据，也不能声称已经可供我们下载训练。

## Qwen3.5 与本项目

[Qwen3.5 官方介绍](https://qwen.ai/blog?id=qwen3.5)说明扩大了中英、多语言、STEM、推理及视觉文本数据；本次没有找到 0.8B 型号可完整复现的原始数据清单、配比及精确训练 token 数。36T 是上述 Qwen3 报告的数字，不应直接套给 Qwen3.5-0.8B。

本项目 R24 方案是随机初始化纯循环网络，不加载 Qwen 权重。此前 100M、1B 是试验里程碑，10B–20B 是后续首轮预算假设，均不保证已经具备 Qwen 的语义能力或达到安审质量门槛。公开语料可继续扩量，是否值得继续由独立学习曲线和任务测试决定。

当前最明显的数据缺口：自然文本尚未扩量与处理；词库合成集主要是用户单句，缺少助手回答、拒答、跨轮上下文和流式风险边界；每词一中一英两句不等于同语言、同词的最小正负对照。补充数据可放在下游派生/新增训练清单中，不能静默改变已冻结的生成 Schema。
